# Features

This file is the master list of features planned for okoze.

Each feature has a unique ID. The ID is used to identify the feature in
branches, commits, tests, and other development records.

The 🟧 marker indicates a feature.
The 🟢 marker in the Implementation column indicates that the feature
has been implemented.

The list is also used as a development map: I review it regularly to
decide what to implement next and to check whether the plan is still
appropriate.

Detailed design decisions and the development history are documented
in the GitHub Wiki and pull requests.
